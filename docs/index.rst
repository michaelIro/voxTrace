voxTrace
==========

voxTrace is a voxel-based Monte-Carlo X-ray ray tracer for quantitative
confocal micro X-ray fluorescence (CMXRF), written as a single
performance-portable C++ core that runs on CPUs, NVIDIA/AMD GPUs and Apple
silicon.
